# 2026-10-21 본문 검토 01: 검토 기능 배포와 첫 15개

운영 계획 version 1과 마지막 체크포인트, 실행 지침 및 지역 정비 13번 기록을 읽은 뒤 같은 작업을 이어갔다. 지역 정비 14번에서 남은 37개를 운영 반영해 공식 현존 확인 430→467/467개를 완료했다. 주소 응답 일치 464개와 미확인 3개를 구분했다. 그 결과를 완료 기록으로 저장·재조회한 다음 review/running으로 이동했다. 지역별 원문 행·해시·처리 ID는 별도 14번 영수증과 작업 기록에 보존했다.

본문별 검토 API가 없어 먼저 작은 기능을 구현했다. 원문·권리·지역 연결 상태 지문, 예상 리비전, 여섯 항목(명칭·연대·전승·상충·이용조건·공간 범위)의 근거를 검사하며 새 검토와 감사 이력을 원자적으로 추가한다. 반복 요청은 같은 기록을 반환하고 동시 수정은 충돌로 거절한다. 자료·분류·원문이 바뀌면 이전 검토는 오래된 기록으로 표시하고 완료 집계에서 제외한다. 현재 본문은 본문이 있는 최신 자료 버전 기준이다. 자료 상세에서 검토 근거를 읽고 백업에도 새 테이블을 포함하도록 했다.

기능 소스 `175475b9220e9d456bcddd3184a8e59737a1b5b3`를 테스트 **135/135**, 타입 검사와 빌드 후 기존 소유자 전용 사이트 **version 22**로 배포했다. 배포 ID `appgdep_6ad8ab1158408191bc228df4b40dc67c`, saved version `appgprj_6acd53ff39588191b6c07a038ece0771~appgver_682e7795c7148191ab1ca02190be9d86`, 결과 succeeded다. `0004_sharp_metal_master.sql`은 기존 자료를 고치지 않고 검토 테이블·인덱스를 추가했다. 테스트에는 입력·날짜·공간 범위 검사, 전승·미해결 항목의 완료 승격 차단, 본문·권리·버전 불변, 동시 수정, 중복 방지, 감사 실패 롤백, 메타데이터 변경 후 완료 집계 회귀를 포함했다.

소유자 1명만 허용된 custom 정책 revision 1, 외부 방문자·그룹·편집자 0개를 배포 후 다시 확인했다. 화면 시각 검증은 기존 다른 개발 서버가 있어 관리형 preview가 시작되지 못했으므로 미완료다. 이를 테스트·빌드·운영 API 검증 통과와 구분한다. 기존 개발 서버는 중단하지 않았다.

현재 본문 전체 638개를 먼저 읽고 그중 ID 순 첫 재서술 15개를 검토했다. 2026-10-21 공식 원문 네 페이지에서 방학동·쌍문동·마포구 신정동·신천동·증산동 **5개**의 기존 자체 요약을 대조했다. 학·지세·효자문·시루뫼 이야기는 전승으로 보존했다. 역사적 권역을 현행 행정동·법정동 경계나 개별 건물·부지에 연결하지 않았다. 권리 미확인은 보관·재사용 허용으로 승격하지 않았고 원문·사진·영상을 새로 적재하지 않았다.

나머지 **10개**는 원문 접근 실패로 needs_review를 저장했다. 서울지명사전 6개는 조회 도구에서 원문 접근 불가였고, 영등포구 1개·성동구 2개·관악구 1개는 HTTP 502 또는 시간 초과였다. 원문을 읽지 못한 문장의 진위·연대를 판정하거나 기존 본문을 삭제·수정하지 않았다. 단순 접속 장애를 사이트 전체의 영구 중단 사유로 취급하지 않았다.
