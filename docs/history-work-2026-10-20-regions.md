## 구현 및 검증 대상

- 주소 제공기관에서 직접 받은 명칭·코드와 조회일·정확한 응답 필드 위치를 보존하는 제한된 검토 API.
- 기존 ID·자료 버전·원문 분류·공개 범위 유지. 코드 상충은 덮어쓰기 대신 별도 기록.
- 검토 리비전과 감사 이력의 원자적 저장, 중복 요청 반환, 동시 수정 및 원본 상태 충돌 방지.
- 지역 현황에서 코드 입력 수·주소 관측 수를 구분하며 생성·폐지 상태 미확인을 안내.
- 백업 스키마 4에 지역 검토 이력 포함.

## 운영 결과의 기준 기록

배포 후의 실제 처리 ID·검토 리비전·원문 근거는 운영 DB `archive_region_reviews`와 `archive_audit`가 기준이다. 실행 전후 지표·실패·다음 커서는 `/api/archive/task`의 checkpoint에 저장한다. 이 문서는 구현 및 조사 방법 기록이며 운영 등록 완료를 사전에 주장하지 않는다.

## 운영 처리 결과

- 종로구 가회동부터 와룡동까지 50개 법정동을 주소 응답과 대조하고 모두 revision 1 / `address_observed`로 저장했다. 전체 50개 재조회에서 명칭·코드·근거 필드·조회시각을 대조했다.
- 공식 코드 입력: 2 → 52개. 주소 응답 대조: 0 → 50개. 미확인·상충 기록: 0개. **공식 생성·폐지 상태는 아직 직접 대조하지 않았다.**
- 첫 5개를 같은 요청으로 다시 처리했을 때 기존 revision·검토 ID를 반환했고 기록은 늘지 않았다. 다른 기존 코드를 넣은 요청은 HTTP 409로 거절됐다.
- 전체 지역 목록을 전후 비교해 50개의 `official_code`만 달라졌고 기존 ID·명칭·분류 근거·별칭·기준일·생성일은 유지됐다.
- 자료 524, 본문 638, 파일 20, 연표 21, 기존 자료 버전 524가 유지됐다. DB 명칭 467개 모두의 본문 연결도 유지됐다.
- 테스트 94개, 타입 검사, 빌드 통과. 소유자 전용 기존 사이트 배포 후 운영 API·coverage의 새 집계를 재조회했다. 화면의 브라우저 시각 검사는 이번 묶음에서 수행하지 않았다.
- 처리 ID와 검토 ID·코드·조회시각은 `data/region-code-observations-2026-10-20.json`에 기록했다. 검토 근거 응답은 운영 `archive_region_reviews`와 감사 이력에 보존한다.
- 실패 및 한계: 행정표준코드 전체자료 직접연결은 HTTP 503/시간초과. 필드 의미 안내 문답도 직접 페이지 열람에서 404/503이 나와 검색 색인 본문 확인과 구분한다. 실제 코드 관측은 운영 서버에서 공식 주소 API를 직접 조회한 결과다. 로컬 실행 클라이언트의 긴 숨김 입력 오류는 DB 변경 전 발생했고 입력을 분리한 후 재개했다.
