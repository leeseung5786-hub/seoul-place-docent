# 노원구 사진·항공사진·지도 조사자료 반영

첨부 `NOWON-HISTORY-PHOTOS.csv`의 신규 79행을 사진·지도 조사 페이지에 추가했다. 함께 첨부된 `성동구_누적_2026-10-21(1).csv`는 이미 배포된 성동구 107행의 원본과 바이트까지 동일하므로 중복 등록하거나 원본을 교체하지 않았다. 기존 Site와 공개 범위를 유지한다.

| 법정동 조사묶음 | 추가 행 |
|---|---:|
| NOWON-월계동-001 | 19 |
| NOWON-공릉동-001 | 18 |
| NOWON-하계동-001 | 10 |
| NOWON-중계동-001 | 12 |
| NOWON-상계동-001 | 20 |
| 합계 | 79 |

매체는 사진 71행·항공사진 7행·지도 1행이다. 원문 확인·검토 대기 74행과 원문 미확인 후보 5행, 링크만 확보 78행과 접근 불가 1행을 원본대로 보존한다. 공개 미리보기 78개는 링크이며 이미지 파일을 새 복제하거나 자동 표시하지 않는다. 이용조건, 출처, 캡션, 조사자 관찰 구분, 과거 행정구역 표기와 미확인 관계를 그대로 유지했다. 도봉구 상계동이라는 과거 장소 표기를 현재 분류 노원구와 함께 보존하고 특정 건물·필지 일치로 승격하지 않는다.

다섯 조사묶음은 원본 파일 하나를 공유한다. 모든 묶음에서 다운로드되는 원본은 79행 전체이며, 각 묶음의 수록 행 수와 공통 파일의 전체 행 수를 구분해 안내한다. 자료의 dataRow는 동별 재번호가 아닌 공통 원본의 실제 데이터 행 번호다. 원본 CSV 개수 표시는 중복 경로를 제거해 집계한다.

기존 통합자료와 원문 URL이 겹치는 신규 조사 2행은 기존 같은 원문 탐색으로 연결했다. 조사 기록은 각각 유지하며 전체 행 수를 고유 사진 수로 표현하지 않는다. 통합조사와 기존 조사 사이의 겹치는 원문 항목 수는 66→68행이다.

전체 조사목록은 5,315→5,394행(시각자료 5,373행·건물 카드 21행), 조사묶음은 52→57개, 연결 가능한 원문 URL은 2,403→2,480개다. 원문 미확인 후보는 172→177행이다. 최종 홈페이지 반영일이 오래된 통합자료 실행일로 되돌아가지 않도록 최신 반영일을 사용한다.

## 검증

- 신규 79행의 모든 필드·자료 ID·공통 파일 행 번호가 첨부 CSV와 일치한다. 다운로드 원본 바이트도 첨부와 같다.
- 기존 개별 조사 3,753행은 파생 항목까지 그대로다. 통합 마스터 1,562행과 지역 연결·조사 이력은 바이트가 같으며 기존 조사·원본 파일 70개의 SHA-256도 같다.
- 같은 파일을 재처리해 생성 데이터 전체의 해시가 동일함을 확인했다. 중복 행이나 공통 원본의 추가 복사본이 생기지 않았다.
- 사진·통합조사 관련 자동 검사 18개와 타입 검사를 통과했다. 묶음·법정동 검색, 후보 제외 주소 결과, 잘못된 자치구 차단, JSON 내보내기, 원본 해시, 성동구 날짜 안내와 정정 카드 보존을 확인했다.
- 관리형 미리보기는 기존 vinext 서버 충돌로 시작하지 못해 화면 시각 검증을 완료하지 못했다. 배포 빌드와 운영 데이터·원본 다운로드 검증을 이어간다.

자료 검토·권리 상태는 첨부의 조사 결과이며 이번 반영에서 원출처를 새로 대조 완료한 상태가 아니다. 본문 대조 작업의 운영 DB·진행 커서는 수정하지 않는다.
