# 2026-10-20 지역 코드 정비: 구로구~마포구 50개

## 시작과 범위

- 운영 `/api/archive/task`의 계획 version 1, 마지막 `regions / ready` 기록, 소스의 `docs/scheduled-history-work.md`를 먼저 읽었다. 계획은 소스와 일치했고 시작 시 다른 running 기록은 없었다. 이번 묶음은 `regions-20261020-guro-mapo-04`이며 시작·종료 checkpoint를 저장한다.
- Sites에서 소유자 한 사람만 허용하는 custom 정책과 기존 운영 주소를 확인했다. 서비스 접근은 해당 사이트에만 사용했다. 기존 프로젝트 ID, 공개 범위, 비밀값, 자료·본문의 ID와 버전은 변경하지 않았다.
- 이전 커서대로 `review_revision=0` 중 구로구 가리봉동부터 마포구 망원동까지 50개를 선택했다. 구로구 10, 금천구 3, 노원구 5, 도봉구 4, 동대문구 10, 동작구 9, 마포구 9개다. 마포구 전체를 완료한 것은 아니다.

## 운영 처리와 근거

- 기존 `verify-region-address` API가 공식 주소 서버를 직접 조회했다. 자치구·법정동명 완전일치와 단일 코드가 확인된 50개 모두 revision 1 / `address_observed`로 반영됐다. 최종 미확인·코드 상충·데이터 처리 실패는 0개다.
- 공식 근거: https://business.juso.go.kr/addrlink/addrLinkApi.do
- 정확한 위치: `results.juso[].siNm·sggNm·emdNm·admCd`, `roadAddr·jibunAddr`. 확인일 2026-10-20, 개별 조회시각은 08:13:04.228Z~08:14:20.699Z다. 일치 응답, 조회시각, 근거 위치와 한계는 운영 `archive_region_reviews.evidence`에 저장됐으며 검토 ID·변경 전후·리비전과 감사 이력도 보존됐다.
- 코드 입력 139 → 189, 주소 응답 대조 137 → 187, 미대조 330 → 280개다. 기존 코드가 입력돼 있더라도 검토 기록이 없는 2개 항목은 계속 미대조 대상이다.
- 상도1동은 공식 주소 응답의 독립 법정동명과 코드 `1159010300`을 관측했다. 상도동의 관측 코드 `1159010200`과 구분했으며 명칭이 비슷하다는 이유로 두 ID를 합치지 않았다.
- 주소 식별 사실만 기록했다. 역사본문·건물·부지의 동일성, 원문·사진·영상의 복제·재사용 조건을 확인한 것으로 처리하지 않았다. 모든 신규 근거의 `officialLifecycle`은 `not_checked`다.

- 50개 전부의 코드·리비전·공식 명칭·조회시각·근거 위치·일치 응답을 운영에서 재조회했다. 전체 467개 지역의 불변 필드와 대상 외 지역의 전체 응답이 그대로 유지됐다.

- 자료 524, 본문 638, 사진 파일 20, 연표 21, 자료 버전 524와 나머지 자료 통계가 모두 유지됐다. coverage에서 법정동 명칭 467개 모두 본문이 연결돼 있고, 대상 50개의 새 코드·검토 상태가 일치했다.
- 테스트 94개와 `tsc --noEmit --incremental false`를 통과했다. 앱 코드·스키마·운영 계획은 변경하지 않았으므로 빌드·재배포·브라우저 검사를 수행하지 않았다. 자료 변경 영수증과 작업 기록만 소스에 보존한다.
- 처리 ID 50개, 검토 ID·코드·리비전·조회시각·근거 해시와 검증 결과는 `data/region-code-observations-2026-10-20-guro-mapo-04.json`에 저장했다. 인증값과 주소 선택 토큰은 기록하지 않았다.

## 오류와 공식 상태 조사

- 초기 로컬 네트워크 오류는 승인된 네트워크 실행으로 복구했다. 최초 curl 설정에서 한글 JSON의 이스케이프가 올바르게 전달되지 않아 50개 요청이 `REGION_NOT_FOUND`로 거절됐다. 이때 전체 지역 데이터가 바뀌지 않았음을 재조회로 확인했다. ASCII JSON 이중 인코딩으로 수정하고 표본 성공을 확인한 뒤 같은 50개를 정상 처리했다. checkpoint의 한글 요약도 수정 후 재조회했다.
- `https://www.code.go.kr/stdcode/regCodeL.do`, 제공기관 Q&A, 국토교통부 파일데이터와 행정안전부 공지의 직접 연결은 HTTP 503이었다. 검색 도구로 공식 코드 조회 첫 화면은 열람했으나 개별 현존·폐지 행은 확보하지 못했다. 로그인이나 접근 정책을 변경하지 않았다.
- 후속 공식자료 후보: https://www.data.go.kr/data/15123287/fileData.do (`국토교통부_법정동코드_20260929`). 2026-10-20 공식 상세 설명에서 `법정동코드·법정동명·폐지여부` 컬럼, 수정일 2026-09-29, 이용허락범위 제한 없음 표기를 확인했다. 설명 화면 열람과 CSV 파일의 개별 행 확보는 구분한다. 파일을 아직 내려받지 못했으므로 현존·폐지 검증 완료 근거로 사용하지 않았다.
- 공식 파일 확보 후 기준일·원문 위치·해시·명칭/코드 일치를 기록하고, 필요하면 검증·충돌 방지·감사 이력을 갖춘 작은 상태 확인 API를 먼저 구현·테스트·배포한다. 자료의 기준일을 조회일과 동일시하지 않는다.
