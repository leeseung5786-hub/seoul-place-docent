# 사용자 제공 서울 도시사 영상 조사 보고서

2026-10-21 사용자가 `서울 도시 역사자료 아카이브 구축 보고.pdf`를 현재 사이트에 반영하도록 요청했다. 기존 소유자 1명 전용 정책과 지역 코드 정비 예약의 단계·커서는 유지한다.

## 수록 범위

- `/archive/video-research`: 보고서 원본과 215개 조사 항목. 차수·문서 표기 채널·주제·문서 속 사건 연도·검색어·ID 불일치 필터, 20개씩 페이지 이동, 쪽수별 PDF 열기, 문서 원시 행, 후보 검색, JSON 내보내기를 제공한다.
- `/documents/seoul-city-history-report-2026-10-20.pdf`: 사용자가 제공한 PDF와 바이트 단위로 동일한 원본. SHA-256 `8f08de6c48fc998ab76731045b39a1bdfea3d1cf13b9af65f6c56436ef281179`.
- `/api/archive/reports/city-history`: 전체 문서 메타데이터·추출 행. `?download=1`은 원래 출처와 검토 상태를 포함한 JSON 다운로드다.
- 메인 메뉴 및 역사자료 DB의 보고서 안내에서 접근한다.
- D1에는 **보고서 문서 1건**의 목록과 수집 근거만 등록한다. 215개 조각을 공식 영상 215건·검토된 역사 본문·연표로 생성하지 않는다. `data/uploaded-city-history-report-capture-2026-10-21.json`으로 기존 capture API에서 멱등 적재한다.

## 원본 검토 결과

PDF는 Gemini 대화 출력물 15쪽이다. 120~132차 각 15행과 133차 20행, 총 자료 행 215개·주장 행 215개가 있다. 문서에서 주장하는 누적 2,000건 전체의 JSONL·영상·메타데이터 파일은 첨부되어 있지 않다.

페이지 1과 15를 렌더링해 오른쪽 잘림을 확인했다. 모든 자료·주장 행은 완전한 JSON이 아니며 영상 식별자를 포함한 완전한 URL은 0개다. 문장을 추측해 완성하거나 잘린 링크를 동영상 상세 URL로 연결하지 않는다. `statementComplete:false`, `videoUrl:null`, `reviewStatus:unverified`를 유지한다.

121차 자료의 9번째 행은 `REC_YT_1709`, 주장 연결 값은 `REC_YT_1809`다. 두 원문 값을 모두 보존하고 같은 차수의 행 순서로 임시 대조했음을 표시한다. 다른 214개는 자료 ID와 주장 연결 ID가 일치한다. ID가 유일하다는 이유로 고유 영상이라고 판단하지 않는다.

촬영일·업로드일·사건일과 PDF 출력 시각을 혼합하지 않는다. 문서 속 사건 연도만 탐색 필터에 사용하고, DB 자료의 발행일·대상 시기는 비워 둔다. 문서 내부의 검증·구축 완료 주장을 이 사이트의 완료 상태로 전환하지 않는다. 문서의 채널명을 실제 채널이나 영상의 존재를 확인한 것으로 간주하지 않는다.

이용허락은 사용자가 제공한 보고서를 기존 소유자 전용 사이트에 수록하는 범위다. 제3자 영상의 복제·재사용 권리는 미확인이다. YouTube 링크는 `results?search_query=` 후보 검색만 제공하며 원본 확인 링크나 임베드로 표시하지 않는다.

## 재현 및 후속 조사
