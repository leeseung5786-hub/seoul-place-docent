# 사진 출처 연결 방식

주소를 고르면 `/api/place-photos`가 아래 출처를 함께 조회합니다. 하나가 실패해도 나머지는 그대로 보여 줍니다.

| 출처 | 방식 | 표시 조건 |
|---|---|---|
| 서울기록원 서울사진아카이브 | `archives.seoul.go.kr/photo/list?query=` 검색 후 각 `/item/번호` 상세 페이지 확인 (키 불필요) | 접근유형 **공개** 이고 이용유형 **제한없음** 인 기록만 |
| Wikimedia Commons | 좌표 반경 검색, 근처 장소 분류, 동 이름 검색 | CC·퍼블릭도메인 등 공개 라이선스만 |
| 한국어 위키백과 | 근처 문서의 대표 사진 (Commons 라이선스 재확인) | 위와 같음 |

- 서울기록원 검색어: 법정동 이름 → 기본 동 이름(삼선동2가→삼선동, 여의도동→여의도) → 도로명 → (사진이 적을 때만) 자치구 이름. 자치구 이름으로 찾은 사진은 "자치구 배경"으로 표시합니다.
- 서울기록원 사진은 이야기 카드(시간순)와 맨 위 사진 띠에 함께 나오고, 위키미디어 사진은 사진 띠에만 나옵니다.
- 팀이 조사한 자료와 같은 사진(같은 파일·같은 원문 주소)은 다시 넣지 않습니다.
- 결과는 서버 메모리에 6시간 저장합니다.

## 새 기관 추가하기
`lib/seoul-archives.ts`처럼 `PlacePhoto[]`를 돌려주는 함수를 만들고 `lib/place-photos.ts`의 `findPlacePhotos` 안 `named` 목록에 추가하면 됩니다. 이용조건을 페이지에서 확인할 수 없는 사진은 넣지 않습니다.
