# 서울 전역 통합조사 자료 반영

사용자가 첨부한 최종 마스터 및 조사 이력 11개를 기존 홈페이지에 반영한다. 기존 Site ID와 소유자 전용 공개 범위를 유지한다. 운영 DB의 기존 자료·본문·검토 이력은 변경하지 않는다.

## 반영 범위

| 항목 | 반영 수량 | 처리 |
| --- | ---: | --- |
| 최종 자료마스터 | 1,562행 | 사진 1,085·지도 79·도면 398, 검색 및 주소별 조사자료에 연결 |
| 자료지역연결표 | 1,703행 | 자료·대상 ID 및 자치구·법정동·코드를 전수 대조 |
| 조사대상목록 | 493곳 | 서울 전체 1·자치구 25·법정동 467 |
| 첨부 자료상 법정동 목표 충족 | 461곳 | 홈페이지 원문 검토 완료와 구분 |
| 보류 법정동 | 6곳 | 강일동·남현동·가산동·연남동·영등포동3가·용산동4가 |
| 조사로그 | 3,869행 | 검색·페이지 단위 열람 이력 |
| 제외목록 | 925행 | 제외 사유와 재검토 조건을 제공, 채택 자료에 추가하지 않음 |
| ID 변경 | 11행 | 이전 ID 검색을 현재 자료 ID에 연결 |
| 수정내역 | 4,389행 | 별도 이력으로 보존 |
| 누적 신규자료 | 1,542행 | 마스터의 증분 이력이므로 중복 등록하지 않음 |
| 원본 다운로드 | 11개 | CSV 8개·JSON·Markdown·XLSX, 첨부와 바이트 일치 |

기존 사진·지도·건물 조사목록 3,646행은 그대로 보존했다. 통합 검색은 총 5,208행(시각자료 5,187행·건물 카드 21행)이며 사진 수나 고유 이미지 수를 뜻하지 않는다. 새 자료 중 66행은 기존 조사와 원문 URL이 겹친다. 각 조사 ID와 원본 필드는 보존하고 전체 목록에서 같은 URL의 항목을 연결한다. 서로 다른 접속 URL은 총 2,399개이며 컬렉션·검색 페이지도 포함한다.

지역 연결이 있는 신규 법정동은 465곳이다. 기존 동별 조사에 있는 연남동을 합쳐 통합 검색의 동 연결 범위는 466곳이다. 조사대상 467곳과 이 수치는 구분한다. 첨부 파일에서 보류인 동에 기존 다른 조사자료가 있어도 첨부 처리상태는 변경하지 않는다.

## 제공 기능

- 기존 `/archive/photo-research`의 자치구·법정동·매체·옛 지명·자료 ID 검색에 추가.
- 통합조사 요약, 조사대상·지역 연결·로그·제외·ID 변경·수정내역을 검색하고 페이지별 조회.
- 사진·지도 카드에서 지역별 연결 근거와 원문·시각적 내용 확인 상태를 열람.
- 주소 검색의 사진과 지도 탭에서 법정동 연결표에 근거한 통합조사 자료를 제공. 건물·부지·필지 일치를 판정하지 않음.
- 첨부 원본 11개와 기존 CSV 50개 다운로드를 유지.

## 데이터 보존과 검증

`data/photo-research/bundle.json`, 기존 원본 50개 및 기존 summary/counts는 변경하지 않고 별도 통합 요약 및 추가 데이터로 결합한다. 기존 원본 필드·자료 ID·정정 관계·권리 표기를 보존한다.

자료별 `검토상태`는 모두 첨부 표기인 `원문 확인·검토 대기`로 유지했다. 시각적 내용 확인 상태는 원문 설명 1,418행·원문 항목 131행·원문 제목 13행이며, 이미지 직접 관찰로 승격하지 않았다. 실제 이미지·썸네일은 새로 복제하거나 표시하지 않았다.

조사대상 CSV 첫 헤더는 BOM과 인용부호를 포함한 `대상ID` 표기였다. 파싱된 검색용 필드명만 정규화하고 원본 다운로드는 변경하지 않았다. 연결표 1,703행의 자료·대상 참조 및 자치구·법정동·법정동코드 불일치는 0건이다. 등록한 대상은 현행 서울 법정동 목록과 일치한다. 기존 지리 판정기로 확인한 서울·경기 외 확정 항목은 0건이다. 지명 판정이 미확인인 항목은 첨부 지역 연결 근거와 주소관계 미확인을 함께 표시한다.

기존 동별 CSV 추가 도구는 통합조사 원본이 존재하면 통합 요약도 다시 계산한다. 통합조사 도구는 원본 저장 폴더로 재실행할 수 있고 증분 이력을 다시 자료로 추가하지 않는다.

검증 명령:

```sh
node --experimental-transform-types --import ./tests/ts-resolver.mjs --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

자동 검사 173개와 타입 검사를 통과했다. 마스터 및 지원표의 모든 파싱 필드, 첨부 원본 11개의 바이트·SHA-256 일치를 별도로 확인했다. 기존 3,646행의 필드 보존, 지역 동명이인 구분, 보조 지역 연결, 이전 ID 조회, 중복 URL 연결 및 원본 다운로드를 검사했다.

미리보기는 이전 컨테이너의 잠금 파일 정리 후 정상 실행되었으나 클라우드 브라우저가 `ERR_CONNECTION_REFUSED`를 반환하여 시각 검증은 미완료다. 배포 빌드와 최종 운영 조회 결과는 후속 배포 기록으로 보관한다.
