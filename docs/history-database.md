# 역사자료 DB · 1단계

## 저장 구조와 범위

Cloudflare D1(DB)과 R2(BUCKET)를 사용한다. 스키마는 db/schema.ts, 초기 스키마 전용 마이그레이션은 drizzle/에 있다. 원문 파일을 DB 마이그레이션에 포함하지 않는다. 최초 데이터 적재는 소유자 전용 POST /api/archive/seed로 실행한다. 재실행과 중단 후 재실행을 지원한다.

- 서울 1, 자치구 25, 법정동 명칭 467, 조사 권역 43.
- 자료 목록 45: 서울시 지역 목록·서울 역사 소개 2 + 서울역사박물관 생활문화조사 컬렉션 43.
- 기존 7개 지역 설명과 21개 동네 연표를 28개 재서술 구간으로 이전한다.
- 지역 분류는 탐색용 태그이며 건물·부지 동일성을 검증한 연결표가 아니다.
- 기존 설명의 상태는 legacy_checked. 원문 직접 인용이 아니고 개별 원문 구간 대조가 추가로 필요하다.
- 파일은 기본적으로 보관하지 않는다. 소유자가 자료별 보관 허용과 근거 URL·내용을 입력해야 R2 업로드가 열린다.
- AI 생성과 PDF·이미지 OCR은 이 단계에 연결하지 않았다.

## 기능과 API

사용 화면: /archive. 서울/구/법정동/권역 탐색, 다중어 검색, 자료 유형·검토·이용조건 필터, 상세 출처·본문·버전·변경 기록, 소유자 등록·수정·본문 추가·파일 업로드·백업을 제공한다.

GET /api/archive/stats, /regions, /sources, /sources/:id
POST /api/archive/sources
PATCH /api/archive/sources/:id (expectedVersion 필수, 기존 버전 보존)
POST /api/archive/sources/:id/passages (본문 구간은 검토 대기)
POST /api/archive/sources/:id/assets (multipart file, 최대 10MB)
GET /api/archive/assets/:id (첨부 다운로드, 현재 보관 허용 재확인)
GET /api/archive/export (소유자, 각 테이블 10,000행 초과 시 오류 반환)
POST /api/archive/seed (초기 적재, 반복 실행 시 중복 생성 안 함)

쓰기 요청은 인증된 소유자 이메일(서버 환경 변수) 또는 별도 서버 관리 토큰으로 확인한다. 토큰 값은 브라우저에 보내지 않는다. 크로스 오리진 쓰기 요청을 거부한다. 현재 사이트의 소유자 전용 공개 범위를 유지한다. 공개 범위 변경 시에도 관리 API는 인증된 소유자 또는 관리 토큰만 허용한다.

## 확인

테스트는 실제 SQLite에 생성 SQL을 적용하고 등록·버전·검색·초기 적재·중단 복구·권한·이용조건·파일 지문을 확인한다. 배포 후 D1의 실제 테이블과 개수를 추가 확인한다. 브라우저 QA 도구가 없는 실행 환경에서는 API·빌드·응답 HTML 검증까지만 수행한다.

## 2차 수집: 개별 상세 자료

- scripts/collect-museum-records.py가 공식 컬렉션 43개의 첫 목록에서 자료를 최대 3개씩 선택하고, 실제 상세 페이지를 조회한다. 2000년 이전 시기를 우선 탐색하되 상세 페이지의 시기 항목으로 날짜를 정규화한다.
- 공공누리 유형은 개별 상세 페이지의 이용조건 링크에서 확인한다. 제1유형이 명시된 자료에만 원문 설명 보관 및 변형 재사용 확인을 설정한다. 공개 페이지라는 이유만으로 유형을 추정하지 않는다.
- scripts/prepare-museum-import.py는 확인한 상세 메타데이터, 수록 보고서 쪽수, 출처 표시, 페이지 지문과 원문 설명을 입력 JSON으로 만든다. 실패한 상세 페이지는 원문 확보로 세지 않는다.
- POST /api/archive/capture는 소유자 전용, 1회 1~10건, 최대 400KB이다. 자료별 내용 지문으로 재수집 중복을 방지하고, 변경된 원문은 새 버전으로 보존한다.
- 원문 수집 설명은 source_captured(내용 검토 대기)이며 역사적 사실 항목이나 건물·부지 연결을 자동 생성하지 않는다.
- GET /api/archive/coverage는 구별 목록·본문·원문 설명·보관 파일의 확보 범위를 구분한다.
- 검색은 자료 목록과 본문을 함께 조회한다. 원문 있음·파일 있음·2000년 이전 자료 필터를 제공한다. 날짜가 미상인 자료를 추측해 과거 자료로 분류하지 않는다.
- 원본 이미지가 TIFF인 경우에도 10MB 이내의 파일은 원형 보관할 수 있다. 10MB 초과 원본은 변환하지 않고 링크만 보존한다.

2026-10-16 추가 확보: 개별 상세 자료 129건(43개 컬렉션에서 최대 3개), 공공누리 제1유형 118건·제2유형 11건. 제1유형 118건의 설명만 원문으로 수집하고 제2유형 자료는 목록만 저장한다. 데이터는 data/museum-captures-2026-10-16.json으로 재현 가능하다. 구별 분류는 20개 구에 걸쳐 있으며 미수록 구는 현황에서 0건으로 표시한다.

수집 JSON 가져오기 화면은 최대 2MB·200건을 받고 10건씩 요청한다. 수정된 원문과 목록은 새 버전으로 보존한다. 같은 원본 파일의 SHA-256이 이미 해당 자료에 있으면 중복 저장하지 않는다.

시기 필터는 제공기관 상세 페이지의 `시기` 표기를 기준으로 한다. 자료의 촬영·제작 시점과 설명 속 역사적 사건 시점은 구분해야 하므로, 설명에 나온 연도를 자동 추출해 필터에 섞지 않는다.

## 3차 수집: 동별 사실 요약과 공간 범위

2026-10-16 구청 공식자료 28건을 추가 확인했다. 금천·노원·도봉·성북·송파·양천·강서·구로·은평의 9개 구에서 짧은 사실 요약 74개를 작성했다. data/dong-history-captures-2026-10-16.json이 재적재 가능한 입력이다.

- 법정동 명칭과 일치하는 요약 69개, 여러 법정동에 걸친 공통 동네 설명 5개. 전체 467개 법정동의 역사 완성이나 검토 완료를 의미하지 않는다.
- 개별 원문의 복제 허락은 확인되지 않았으므로 새 자료의 storageAllowed·reuseAllowed는 false이다. 원문·이미지를 적재하지 않고 최소한의 지명·연혁 사실만 별도 문장으로 작성했다. 전승은 전승, 추정은 추정으로 표시한다. 단순 문장 변경이나 AI 작성으로 원자료의 권리가 없어지는 것으로 취급하지 않는다.
- 새 사실 요약 본문은 pending, 자료는 needs_review이다. 개별 역사적 주장에 대한 원전 대조와 내용 검토는 남아 있다. 자동 연표·사실 항목 생성은 하지 않는다.
- 강서구 자료는 공식 페이지 검색 색인에서 본문을 확인했으나 직접 HTTP 조회가 502였다. 페이지 지문을 비워 두고 원문 재조회 필요를 표시했다. 다른 27건은 직접 조회한 HTML의 SHA-256과 확인 시각을 기록했다.
- 원문 본문에서 이름을 확인한 법정동만 exact_name으로 분류한다. 삼선동·동선동·보문동·안암동·월곡동 같은 공통 설명을 각 법정동 세부 가(街)에 자동 복제하지 않는다. 별도 구 맥락으로 분류하고 법정동 집계에서는 제외한다.

추가 스키마 archive_passage_regions는 본문 구간별 지역·관계·분류 근거를 저장한다. 주소·좌표나 개별 부지 연결표가 아니다. capture API의 선택적 sections 배열로 원문 위치·본문 종류·지역명·분류 근거를 함께 입력한다. 명칭 불일치·미등록 지역을 쓰기 전에 거부하고 원문 전사의 이용조건 검사를 유지한다.

현황 API는 25개 구 집계와 467개 동의 명칭 일치 본문 수·원문 수·검토 수를 반환한다. 현재 사용 중인 마지막 수집 버전의 구간만 동별로 집계하며 과거 버전은 상세에서 보존한다. 목록 정보만 수정한 경우 마지막 수집 구간을 유지한다. 동별 미확보 필터와 해당 동 검색, 선택한 동의 본문만 읽기를 지원한다. 백업 schemaVersion은 3이며 11개 테이블을 포함한다.

scripts/collect-dong-pages.py는 실제 구청 메뉴에서 발견한 링크만 조회한다. scripts/prepare-dong-history.py는 조사 캐시를 검사해 수동으로 정리한 사실 요약을 입력 형식으로 변환한다. 원문 HTML은 임시 연구 캐시에만 남기며 배포·소스 저장소에는 포함하지 않는다. 수집 범위는 웹자료이며 보고서 PDF 전문이나 OCR을 확보한 것으로 세지 않는다.
