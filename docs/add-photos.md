# 사진 추가하는 방법 (코드를 몰라도 됩니다)

사진이 없는 동네에 사진을 넣으려면 `data/manual-photos.json` 파일에 항목 한 개를 추가하면 됩니다. 사진 한 장이 항목 한 개입니다.

## 순서

1. 이용할 수 있는 사진을 찾습니다. 서울역사아카이브, 공공누리 표시가 있는 공공기관 자료, 직접 찍은 사진, 촬영자 허락을 받은 사진은 사용할 수 있습니다. **이용조건을 확인할 수 없는 사진은 넣지 마세요.**
2. 사진 위에서 오른쪽 클릭 → `이미지 주소 복사`로 사진 주소(`https://…jpg`)를 복사합니다. 주소는 `.jpg`, `.png`, `.webp` 등으로 끝나야 합니다.
3. 사진이 소개된 원문 페이지 주소도 복사합니다.
4. GitHub에서 `data/manual-photos.json`을 열고 연필 아이콘(편집)을 눌러 아래 틀을 복사해 채웁니다. 항목 사이에는 쉼표(`,`)가 필요합니다.
5. `Commit changes`를 누르면 저장됩니다. 사이트에는 다시 배포한 뒤 반영됩니다.

## 항목 틀

```json
{
  "district": "성북구",
  "dong": "삼선동2가",
  "title": "삼선교 일대 전경",
  "date": "1970년대",
  "imageUrl": "https://example.org/photo.jpg",
  "sourceUrl": "https://example.org/원문-페이지",
  "institution": "서울역사박물관",
  "credit": "서울역사박물관 · 촬영자 이름",
  "license": "공공누리 제1유형",
  "description": "사진이 보여 주는 내용을 한두 문장으로 적어 주세요.",
  "allowDisplay": true
}
```

| 칸 | 필수 | 설명 |
|---|---|---|
| `district` | 예 | 자치구 이름 (예: 성북구) |
| `dong` | 아니요 | 법정동 이름. 비워 두면 그 구 전체의 사진으로 쓰이고, 동 자료가 없는 동네에만 나옵니다. |
| `title` | 예 | 사진 제목 |
| `date` | 아니요 | 촬영·대상 시기 (예: 1970년대). 비우면 시기 미상으로 맨 뒤에 나옵니다. |
| `imageUrl` | 예 | `https://`로 시작하고 이미지 확장자로 끝나는 사진 주소 |
| `sourceUrl` | 예 | `https://`로 시작하는 원문 페이지 주소 |
| `institution` | 예 | 제공 기관 또는 촬영자 |
| `credit` | 아니요 | 화면에 표시할 출처 문구 (비우면 기관 이름) |
| `license` | 예 | 이용조건 (예: 공공누리 제1유형) |
| `description` | 아니요 | 사진 설명 |
| `allowDisplay` | 예 | `true`일 때만 사이트에 나옵니다. 확인이 끝나기 전에는 `false`로 두세요. |

필수 칸이 하나라도 비어 있거나 `allowDisplay`가 `true`가 아니면 사진은 사이트에 나오지 않습니다. 사진 주소를 직접 연결하는 방식이라, 제공 기관이 사진 주소를 바꾸면 사진이 사라질 수 있습니다.
