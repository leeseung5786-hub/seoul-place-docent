# 성수동 국가기록원 동명 지역 자료 제외

2026-10-21 사용자가 성수동에서 `경상북도 선산군 대동면` 자료를 빼도록 요청했다.

운영 조회에서 `/api/records?provider=national&q=성수동&page=1`은 제공기관 전체 783건 중 첫 10건을 반환했다. 9건의 제목이 `경상북도 선산군 대동면 성수동(경상북도 선산군 산동면 성수동)`으로 시작했으며, 나머지 1건은 `(69년)재산조사 대조부 : 성수동1가 성수동2가`였다. 저장된 역사자료 DB의 `선산` 검색 결과는 0건이었다. 기존 DB 연결을 삭제하는 문제가 아니라 실시간 후보 검색의 동명 지역 혼입이었다.

국가기록원 응답을 정규화한 다음, 제목에 명시된 `경상북도 선산군 대동면 성수동` 또는 `경상북도 선산군 산동면 성수동`의 연속 지명과 일치하는 항목을 서버에서 제외한다. 공백·문장부호·전각 표기 차이를 정규화한다. 일반적인 성수동 자료, 경상북도 출신 주민의 서울 생활사 등 다른 서울 관련 후보까지 차단하지 않는다.

모든 검색어와 페이지에 같은 기준을 적용하므로 화면과 기록 JSON 다운로드에 사용하는 API 후보 목록에서 빠진다. 제공기관 원본·원문 링크를 삭제하거나 기존 역사자료 DB·예약 체크포인트를 변경하지 않는다.

원본 783건은 제공기관 검색 총수로 표시하며, 페이지 이동은 제공기관의 10건 단위를 유지한다. 필터를 적용한 전체 건수를 알고 있는 것처럼 새 총수를 만들지 않는다. `excludedCount`는 현재 페이지에서 제외한 수이고 현재 표시 건수와 함께 안내한다. 페이지 전부가 제외된 경우에도 제공기관 전체 검색이 0건인 것처럼 안내하지 않는다.

국가기록원 API 응답과 브라우저 요청에 no-store를 적용해 기존 응답 캐시가 제외 항목을 다시 표시하지 않게 한다. 사진 컬렉션의 기존 서버 캐시는 유지한다.
