# 서울 역사 영상 엑셀 통합 결과

작업 기준: `xeonica/seoul-place-docent` main `d21667960a1fd8905a9daebfcee847f4b9666574`.
작업 브랜치: `codex/history-video-workbooks`.

## 자료 처리 결과

사용자가 전달한 ZIP의 실제 구성은 **엑셀 26개, PDF 1개**다. 요청문에 적힌 PDF 2개 중 하나는 현재 ZIP에 없다. 엑셀은 25개 자치구 각 1개와 서울 도시역사 목록 1개이며, 180개 시트를 모두 읽었다. PDF는 33쪽의 별도 참고문서로 보존했다. 이 문서 안의 지시문은 실행하지 않았고, 재생 확인 주장도 사이트의 독립 검증으로 받아들이지 않았다.

| 구분 | 결과 |
|---|---:|
| 대표 조사대장 원본 행 | 3,740 |
| 링크·영상 ID가 불명확해 확인 대기로 남긴 행 | 63 |
| 같은 상세 URL·YouTube 영상 ID로 통합한 반복 행 | 126 |
| 이번 엑셀의 고유 원문 링크 후보 | 3,551 |
| 기존 통합보고서의 영상 | 204 |
| 기존 보고서와 이번 엑셀의 동일 URL 중복 | 6 |
| 통합 후 고유 원문 링크 후보 | 3,749 |
| 통합 목록 전체: 링크 후보 + 확인 대기 | 3,812 |
| 엑셀 관련 구간 조사 행 | 2,394 |
| 동일 제목·다른 URL로 남긴 중복 검토 묶음 | 28 |
| 사이트에서 독립적으로 재생·권리 검증한 영상 | 0 |

링크 후보 수는 실제 재생 가능한 영상 수가 아니다. 서로 다른 공식 기관의 URL이 같은 원본 영상을 재게시했을 가능성은 남아 있다. URL·영상 ID로 확정하지 못한 제목 중복은 삭제하지 않고 검토 표시만 했다. 미확인 URL과 영상 ID를 추측해 복원하지 않았다.

빠른목록·누적검색·신규·변경이력·ABC 표는 대표 조사 행으로 다시 세지 않는다. 보조 시트의 같은 자료ID는 같은 파일 안의 해당 조사 행에만 연결한다. 행 순서로 다른 항목을 붙이지 않았다. 원래 자료ID, 파일, 시트, 행 번호, 원본 열 배열·셀값·하이퍼링크를 보존한다. 구간표는 원자료에 적힌 시간을 보존하고 형식 검사를 별도로 표시한다. 시간 형태가 맞아도 직접 확인한 구간이라고 표시하지 않는다.

기존 PDF 조사 항목 **215개**, 기존 통합보고서 영상 **204개**, 기존 제외 목록 **17개**는 삭제하거나 덮어쓰지 않았다. PDF 페이지에서 추출한 URL 80개는 별도 참고 관계로 보관했으며, 현재 목록과 확실하게 일치한 URL은 0개여서 영상 행에 자동 병합하지 않았다.

원본 ZIP·엑셀·PDF는 `public/research/video-workbooks/`에서 바이트 그대로 제공한다. 파일별 SHA-256, 대표 시트 선택, 모든 시트의 비어 있지 않은 행 수·자료ID 행 수·URL 후보 행·반복 URL 행·보류 행·대표 자료ID 대응 수는 `import-audit.json`에 있다. 원본 ZIP의 SHA-256은 `6ea7f49d6d9e722f64fdc95c08cdc4316fcafef44216aed44b00760f8b255d3a`다.

## 홈페이지에서 달라지는 점

`자료실·안내 → 영상 조사자료`에서 자치구, 행정동·법정동·장소, 제목·설명·제작기관, 역사적 대상 시기, 자료원, 확인 상태, 엑셀/기존 보고서로 검색한다. 목록은 서버에서 검색하고 12개씩 반환한다. 전체 원자료를 브라우저에 넣지 않는다. 원본 열·출처·권리·재생 확인 표기·구간표는 상세를 펼칠 때 조회한다. 원본 링크와 원본 파일 내려받기를 제공하며, 임의 썸네일이나 검증되지 않은 플레이어는 넣지 않았다.

주소 검색/지도 선택 결과의 기존 영상 패널도 같은 통합 목록을 사용한다. 한 번에 최대 6개를 보여 주며 전체 자료실로 이어진다. 같은 자치구와 법정동이 함께 맞는 후보를 먼저, 지명 관련 후보를 다음에, 자치구·서울 전체 배경자료를 뒤에 표시한다. 행정동을 법정동으로 바꾸거나 지명만으로 건물·부지·주변 거리 일치를 확정하지 않는다. 현재 이 자료에서 독립 확인한 건물·부지·거리 기반 주변 연결은 없으므로 모두 후보 또는 배경으로 표시한다.

시기 필터는 역사적 대상 시기 열에 기재된 연도만 사용한다. 촬영일·제작일·게시일·단순 자료일자를 역사 사건의 시기로 대신하지 않는다. 해당 열에 연도가 없으면 대상 연도 미확인으로 분류한다.

기존 `/api/archive/video-research`의 기본 A/B 보고서 조회·내려받기 응답은 유지했다. 새 화면은 같은 API의 `dataset=combined`를 사용한다. 목록 응답에는 원본 행이 없으며 `id`로 상세를 요청한다. 잘못된 페이지·조건·자료ID는 400 또는 404로 처리한다.

## 변경 파일과 역할

- `scripts/import-video-workbooks.py`, `scripts/requirements-video.txt`: 읽기 전용 가져오기, 헤더별 매핑, 원본 보존, 중복·PDF 관계·시트 집계. 원본 XLSX를 저장하거나 수정하지 않는다.
- `data/video-workbooks/index.json`, `records.json`, `pdf-references.json`: 서버용 목록, 조사 행·보조 행, PDF URL 참고 관계.
- `public/research/video-workbooks/`: 원본 ZIP, 엑셀 26개, PDF 1개, 시트별 감사 목록.
- `lib/video-catalog.ts`, `video-catalog-types.ts`, `video-catalog-api.ts`: 검색·지역 관계·페이지 처리·상세 조회. 클라이언트용 타입/문구와 서버 데이터를 분리한다.
- `app/api/archive/video-research/route.ts`: 기존 API에 통합 목록 모드 추가.
- `app/components/VideoResearchPanel.tsx`, `video-research-panel.css`: 전체 자료실과 주소별 패널의 검색·출처·구간·원본 표시.
- `app/archive/video-research/page.tsx`: 메타 설명을 서울 전체 자료 범위로 갱신. 기존 PDF 항목 구역 유지.
- `tests/video-workbooks.test.mjs`, `tests/video-import.test.py`: 데이터 보존·중복·지역·API·URL·시간 검사.
- `.github/workflows/video-workbooks.yml`: PR에서 원본 재가져오기 일치·테스트·타입·빌드 확인.
- `.gitignore`: Python 실행 중 생기는 캐시 제외.

이전 요청의 사용자 AI 연결/UI 변경은 이 영상 PR의 커밋에 포함하지 않는다. 기존 D1/R2, 호스팅 설정, 운영 환경변수, 문헌·사진 데이터를 수정하지 않았다.

## 검증

- 새 영상 통합 자동 테스트 8개와 Python 가져오기 검사 4개 통과.
- 동일 ZIP을 다시 가져온 뒤 생성 JSON의 해시를 비교해 일치 확인. 기존 출력 ZIP 자체를 입력으로 넣는 재실행도 지원한다.
- 로컬 전체 테스트 286개 중 273개 통과, 13개 실패. 실패한 이름은 수정 전 로컬 작업본과 동일하다. 이 실행에는 앞선 사용자 AI 작업의 테스트 8개도 포함돼 있다.
- `pnpm typecheck`와 `pnpm run build:vercel` 통과. 실제 빌드의 TypeScript 단계도 통과했다. 클라이언트 JS 청크에 원본 자료ID와 전체 카탈로그 지문이 포함되지 않는 것도 확인했다.
- 브라우저에서 전체 3,812개 조회, 성동구·성수동 검색 40개, 2/4페이지 이동, 성수대교 개통의 GN-V004/SD-V068 두 원본 조사 행, 기존 PDF 조사 215개 접근을 확인했다. 모바일 배치에서 목록이 한 열로 바뀌고 가로 넘침이 없는 것을 확인했다.
- 대표 원본 링크 `https://www.gangnam.go.kr/board/mediaarchives/548/view.do?mid=ID01_031203`를 열어 「성수대교 개통」 상세 페이지가 표시됨을 확인했다. 영상 재생이나 임베드 이용 허가는 확인하지 않았다.
- 실제 외부 영상 재생·임베드·타임코드 의미·개별 저작권은 독립 검증하지 않았다. 공식 링크의 현재 접근 성공도 전부 확인했다고 보고하지 않는다.

## 재가져오기와 반영

같은 원본이나 갱신된 동일 구성 ZIP은 다음 명령으로 다시 가져온다. 새 파일명·다른 조사대장 구조는 대표 시트 매핑을 검토한 뒤 추가한다. 시트가 없어졌을 때 임의로 다른 시트를 대표로 선택하지 않고 오류를 낸다.

```sh
python -m pip install -r scripts/requirements-video.txt
python scripts/import-video-workbooks.py "영상 자료 - 김동환.zip"
python tests/video-import.test.py
pnpm test
pnpm typecheck
pnpm run build:vercel
```

이번 변경은 원본 파일을 정적 데이터로 변환하므로 운영 DB 초기화·마이그레이션이나 새 유료 API·환경변수는 필요 없다. 작업 브랜치와 PR로 검토하며 main 병합·운영 배포는 소유자의 승인 후 진행한다.
