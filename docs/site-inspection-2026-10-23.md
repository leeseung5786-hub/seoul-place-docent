# 사이트 종합 점검 및 자료 지역 범위 정리

점검일: 2026-10-23 (한국시간)  
대상: https://seoul-place-history.xeonire.chatgpt.site  
허용 자료 지역: 서울특별시·경기도

## 결과

저장 자료를 점검한 결과, 두 지역 밖의 장소만을 다루는 것으로 확정한 삭제 대상은 **0건**이다. 실제 삭제한 저장 자료도 0건이다. 다른 지역의 이름이 등장한다는 이유만으로 서울 장소의 역사·조형물·교통 연결 기록을 삭제하지 않았다.

| 점검 자료 | 규모 | 범위 밖 단독 장소 확정 |
| --- | ---: | ---: |
| 운영 DB 문헌·기록 목록 | 525건 | 0 |
| 운영 DB 본문 | 638개 | 0 |
| 사진·지도·건물 조사 | 3,646행 | 0 |
| 문헌 조사 문헌표 | 261개 | 0 |
| 영상 조사 보고서 추출 항목 | 215개 | 0 |

문헌 조사 8개 표는 조사대상 493, 문헌 261, 연결 983, 주장·근거 1,025, 초안 50, 연표 833, 시각자료 단서 282, 진행 현황 42행이다. 문헌표의 261개는 운영 DB의 525건과 별도 데이터셋이며 합산해 고유 문헌 수로 제시하지 않는다.

운영 DB는 Sites의 반환된 `next_offset`을 끝까지 따라 읽었다. 잘린 본문 셀 2개는 자료 상세 API의 전체 본문으로 보완했다. 사진·문헌·영상 데이터의 지리 메타데이터와 파일 연결도 검사했다. 판정과 미확인 ID는 `data/site-scope-audit-2026-10-23.json`에 기록했다.

## 적용한 수정

- 국가기록원·사진 컬렉션의 공통 지역 허용 기준을 서울에서 **서울·경기**로 조정했다. 다른 광역자치단체와 지역 미확인 검색 후보는 페이지·다운로드에서 제외한다.
- 경기도 및 시·군명, 옛 경기도 지명, 일부 한자·영문 표기를 판별한다. 광주시·중구·강서구와 같은 중복 지명은 확인된 근거 없이 서울·경기로 승격하지 않는다.
- 자료의 실제 장소와 소장처 주소를 구분한다. 등록 검증에도 같은 범위를 적용했다.
- 화면의 지역 안내와 제외 건수 명칭을 변경하고, API에 `geographicScope`와 `outsideScopeCount`를 표시한다.
- `/favicon.ico` 요청이 기존 `/favicon.svg`로 연결되도록 경로를 보완했다.

주소 검색 서비스 자체는 기존 서울 주소 조회 범위를 유지한다. 경기도를 허용한 것은 수록 자료의 지역 기준이다.

## 보존 판단의 예

- 종로구 탑골공원 부조상 사진 4개는 강원·경남·전북·제주 사건을 묘사하지만 설치·촬영 장소는 서울이다.
- 국가기록원 부산분원 소장 지도는 소장처가 부산이라는 이유로 삭제하지 않는다. 대상지가 옛 경기도 고양군 등으로 적혀 있는 자료는 허용 범위다.
- 서울·인천/부산을 잇는 도로, 김포공항이 포함된 공항철도에 관한 보고서 발췌 6개는 서울 구간이 있는 연결 기록이다. 서울 밖만의 장소 자료로 확정하지 않았다.
- 세종로의 ‘세종의 묘호’ 설명은 세종시 자료로 판정하지 않는다.

## 검증

- 기존 검사 161개를 모두 통과했고, 지역 판정 회귀 검사를 보강한 전체 **165개**도 통과했다.
- TypeScript 검사 및 `git diff --check`를 통과했다.
- 운영 주소 검색, 국가기록원 검색, 사진 컬렉션 검색, 문헌·사진·영상 목록, 자료 목록·상세·지역 목록·현황 API가 HTTP 200으로 응답했다.
- 실제 선택 주소의 `/api/place` 응답에서 건축물대장 `ok`, 좌표 `ok`, 지역 역사 1개 연결을 확인했다. 잘못된 토큰은 HTTP 400 `INVALID_TOKEN`으로 거부했다.
- 기존 CSV의 행·해시·ID·지역 연결 검사, 원문 URL과 중복·정정 카드 관련 기존 검사를 통과했다.
- 배포 빌드와 운영 배포가 완료됐다. 배포 후에도 문헌 525건·본문 638개·사진 조사 3,646행을 확인했다.
- 운영 국가기록원 성수동 첫 페이지에서 범위 밖 9건과 지역 미확인 1건을 제외했고, 경기도 수원시 검색 첫 페이지에서는 10건이 정상 표시됐다.
- `/favicon.ico`는 HTTP 308, 대상 `/favicon.svg`는 HTTP 200으로 응답했다. 배포·운영 검증 요약은 `data/site-inspection-verification-2026-10-23.json`에 보존했다.

## 한계

브라우저의 보안 정책으로 화면 접근이 거부되어 시각·클릭·모바일 화면 검증은 완료하지 못했다. 미리보기 서버는 과거에 복사된 잠금 파일을 정리해 정상 시작했으며, 점검 후 종료했다.

이 점검은 메타데이터·본문 표기와 기능의 점검이다. 원문 전체의 역사적 사실을 새로 확정하거나, 원래 남아 있던 본문 대조 보류와 지역 연결 경고를 해소한 작업은 아니다. 지역 표기가 불명확한 저장 항목은 자동 삭제하지 않고 기존 검토 상태를 보존했다. 원문 재확인 없이 그 항목을 서울·경기의 검증 완료 자료로 취급하지 않는다.
