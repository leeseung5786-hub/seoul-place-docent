# 성동구 누적 사진 조사자료 반영

첨부 `성동구_누적_2026-10-21.csv`의 `SDG-HIST-001-P001`부터 `P107`까지 107행을 기존 사진·지도 조사 페이지에 추가했다. 사이트 ID 및 기존 소유자 전용 공개 범위는 유지한다.

- 조사묶음: `SDG-HIST-001`, 자치구 단위 성동구 조사자료.
- 매체 원문 표기: 107행 모두 `사진(현재 모습)`.
- 개별 기관자료 ID 107개, 기관 컬렉션 접속 URL 4개. 개별 사진 열람이나 이미지 파일 확보를 의미하지 않는다.
- 원문 확인·검토 대기 상태 및 원본 보관 불가·표시 권리 미확인 등의 원래 표기를 유지한다.
- 건물 일치 후보 14행·부지 일치 후보 37행·동네 관련 39행·주변 관련 17행을 원본대로 보존한다. 동·건물·필지 자동 일치로 승격하지 않고, 주소 결과에는 성동구 자치구 단위 자료로 연결한다.

성수대교 32행은 촬영·제작일 열이 `1979.10.`이지만 역사적 대상 시기 설명에서 이를 최초 건설 시기라고 명시하고 실제 사진 촬영일은 목록에 없다고 설명한다. 원본 열을 수정하지 않고 목록·카드에 날짜 해석 안내를 추가했다. 나머지 75행에 같은 경고를 적용하지 않았다.

기존 원본 CSV 50개의 SHA-256 및 기존 3,646행의 원본 필드를 대조해 모두 유지됨을 확인했다. 기존 통합조사 마스터 1,562행과 지역 연결·조사 이력·원본 11개도 유지한다. 전체 통합 목록은 5,208→5,315행(시각자료 5,294행·건물 카드 21행), 자치구 단위 묶음은 3→4개다. 전체 접속 URL은 2,403개이며 조사 항목 수는 고유 사진 수가 아니다.

신규 107행은 첨부 CSV의 모든 필드와 일치하고 다운로드 파일도 첨부와 바이트가 일치한다. 검색 API의 자치구·묶음 필터, JSON 내보내기, 기존 통합조사 연결과 날짜 안내를 자동 검사했다. 전체 자동 검사와 타입 검사를 통과했다.
