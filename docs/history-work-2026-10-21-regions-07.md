## 필요한 작은 기능과 배포 제약

- 기존 현존 상태 API는 먼저 주소 응답의 정확한 명칭·코드 일치를 요구한다. 첫 페이지 미관측 항목을 처리하기 위해 별도 `verify-region-official-code` 경로를 구현했다. 현재 코드 null, 가장 최근 검토가 완전일치 후보 0개의 주소 미확인, 공식 원문의 정확한 ID·자치구·전체 명칭·현존 행 일치 조건에서만 빈 코드를 입력한다.
- 기존 코드·복수 일치 코드·중복 코드·리비전 상충을 보호하고, 코드 변경·검토·감사 이력을 한 트랜잭션으로 저장한다. 호출자가 코드·상태·출처를 임의로 공급할 수 없다. 주소 미확인 기록을 삭제하거나 주소 일치로 변경하지 않는다.
- 근거에 `verificationBasis:official_snapshot_only`와 주소 미확인 검토 ID, 첫 페이지 검색 한계를 남긴다. `addressUnconfirmed`·`officialCodeOnly` 별도 지표와 화면 설명도 추가했다. 이 기능의 상태는 **구현 완료·배포 미완료**다.
- 테스트 114개·타입 검사·빌드·diff 검사를 통과했고 기능 커밋 `b891cc41e83ca81c66d63590fbf59af27768a879`를 기존 소스에 동기화했다. 첫 테스트 실패는 SQLite 결과 객체와 일반 객체의 prototype 비교 차이였으며 비교 대상을 정규화한 후 114개 전부 통과했다.
- 동일한 빌드 아카이브로 비공개 통합 배포와 별도 버전 저장을 시도했으나 새 버전이 저장되지 않았다. 후자의 반환 오류는 `MCP -32603: Internal error`다. 첫 호출은 정상 구조화 결과를 받지 못했다. 최신 버전 조회에서 18을 확인했으며 새 버전·배포 ID를 추정하지 않았다. 기존 운영 버전 18과 공개 범위를 유지했다. 새 기능은 운영에서 사용하지 않았다.
- 관리형 미리보기는 다른 vinext dev 서버가 이미 있다는 오류로 시작하지 못했고 상태 조회는 stopped였다. 알 수 없는 기존 프로세스를 종료하지 않았다. 브라우저 시각 검증은 미완료다. 스키마·마이그레이션·인증 정책은 변경하지 않았다.
